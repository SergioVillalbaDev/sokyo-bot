# 09 · Glosario

| Término | Qué significa |
|---|---|
| **API** | Puerta para que un programa hable con un servicio (por ejemplo, el bot con Binance) |
| **API key / secret** | "Usuario y contraseña" para que un programa use tu cuenta. Nunca se comparten |
| **Apalancamiento** | Operar con dinero prestado (2x, 10x...). Multiplica ganancias y pérdidas. El bot no lo usa |
| **Backtest** | Probar una estrategia con datos del pasado |
| **Bajista / alcista** | Que baja / que sube |
| **BTC** | Bitcoin |
| **CAGR** | Rentabilidad media anual compuesta |
| **Circuit breaker** | Freno de emergencia: detiene las operaciones nuevas tras pérdidas |
| **Comisión** | Lo que cobra el exchange por operación (~0,1 % en Binance spot) |
| **Comprar y mantener** (*buy and hold*) | Comprar y no vender. Se usa como referencia para comparar |
| **Cruce de medias** | Cuando una media móvil pasa por encima o por debajo de otra |
| **Drawdown** | Caída desde el máximo anterior de la cuenta, en % |
| **EMA** | Media móvil exponencial: precio medio que da más peso a lo reciente |
| **Esperanza** | Lo que se gana de media por operación, contando ganadoras y perdedoras |
| **Exchange** | Plataforma donde se compran y venden criptomonedas (Binance, Kraken...) |
| **Factor de beneficio** | Total ganado ÷ total perdido. Por encima de 1 es rentable |
| **FIFO** | *First in, first out*: lo primero que compras es lo primero que vendes (para Hacienda) |
| **Futuros** | Contratos para apostar al precio sin tener el activo. El bot no los usa |
| **Hueco** (*gap*) | Cuando el precio abre muy lejos del cierre anterior, saltándose niveles |
| **KYC** | Verificación de identidad que piden los exchanges |
| **Liquidación** | Cierre forzoso de una posición apalancada cuando pierdes tu garantía |
| **Liquidez** | Estar "en liquidez" = tener el dinero en euros, sin comprar nada |
| **Look-ahead bias** | Error de usar en un backtest información que aún no se conocía |
| **Mercado lateral** | El precio sube y baja sin una dirección clara |
| **Orden a mercado** | Comprar o vender ya, al precio que haya |
| **Orden limitada** | Comprar o vender solo a un precio concreto o mejor |
| **Orden mínima** | Importe mínimo que acepta el exchange por orden (~5 € en Binance) |
| **Out-of-sample** | Datos que no se usaron para elegir los parámetros. Sirven para comprobar de verdad |
| **P&L** | *Profit and loss*: ganancia o pérdida |
| **Paper trading** | Operar en directo con dinero ficticio |
| **Par** | Lo que compras y con qué pagas, por ejemplo BTC/EUR |
| **Posición** | Lo que tienes comprado ahora mismo |
| **Riesgo por operación** | Cuánto puedes perder como máximo en una operación si salta el stop |
| **Sobreajuste** (*overfitting*) | Ajustar una estrategia tanto al pasado que deja de servir para el futuro |
| **Slippage** | Diferencia entre el precio esperado y el que te dan de verdad |
| **Spot** | Comprar el activo real, sin préstamos. Lo que usa el bot |
| **Spread** | Diferencia entre el mejor precio de compra y el de venta |
| **Stop-loss** | Venta automática si el precio cae un % desde la compra |
| **Temporalidad** | Duración de cada vela (1 h, 4 h, 1 día...) |
| **Testnet** | Copia de un exchange con dinero falso, para pruebas |
| **Tasa de acierto** (*win rate*) | % de operaciones que acaban en ganancia |
| **Trend following** | Seguimiento de tendencia: subirse a las subidas y bajarse cuando acaban |
| **USDT** | "Dólar digital": criptomoneda que vale aproximadamente 1 $ |
| **UTC** | Hora universal. España es UTC+1 en invierno y UTC+2 en verano |
| **Vela** | Resumen del precio en un periodo: apertura, máximo, mínimo y cierre |
| **Volatilidad** | Cuánto y con qué rapidez se mueve el precio |
| **Whipsaw** | "Latigazo": señales falsas seguidas en un mercado lateral |
